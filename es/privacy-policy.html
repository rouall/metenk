Política de privacidad

1. Información general

Nos tomamos muy en serio tu privacidad. Esta política de privacidad detalla cómo nuestra extensión de navegador recopila, usa, almacena y protege tu información personal. Al usar nuestro producto, aceptas los términos de esta política de privacidad.

2. Uso de los permisos

Nuestra extensión requiere los siguientes permisos para ofrecer una experiencia completa:

Permiso de almacenamiento

Se usa para guardar los tiempos de pomodoro personalizados, las listas de tareas y los ajustes de la extensión para usarlos más adelante.

Permiso de notificaciones

Se usa para mostrar notificaciones de tareas y del temporizador pomodoro.

Permiso de documento fuera de pantalla

Se usa para seguir ejecutando el temporizador pomodoro, la cuenta atrás y los recordatorios de tareas cuando la extensión no está abierta.

Permiso de panel lateral

Se usa para mostrar las listas de tareas y el temporizador pomodoro en la barra lateral del navegador, para que puedas ver y gestionar tus tareas en cualquier momento.

Permiso de alarmas

Se usa para la función de recordatorio del temporizador pomodoro personalizado.

Permiso de pestaña activa

Se usa para recordar la última posición y el tamaño de la ventana y restaurarlos fácilmente la próxima vez.

Permiso DeclarativeNetRequest

Se usa para corregir las cabeceras de solicitud de los reproductores integrados de YouTube.

Permisos de host

Estos permisos de host son necesarios para establecer la cabecera Referer en la reproducción integrada de YouTube y para obtener títulos públicos de vídeos desde YouTube oEmbed y la API oficial de Bilibili. Durante este proceso no se recopilan cookies, credenciales ni datos de navegación.

3. Compromisos de protección de datos

Nos comprometemos con las siguientes medidas de protección de datos:

  • No venderemos ni transferiremos datos de usuarios a terceros para fines distintos de los usos aprobados
  • No usaremos ni transferiremos datos de usuarios para fines ajenos al propósito único de nuestro producto
  • No usaremos ni transferiremos datos de usuarios para determinar la solvencia crediticia ni para fines de préstamo

4. Almacenamiento y seguridad de los datos

Aplicamos medidas de seguridad estándar del sector para proteger tus datos:

  • Todos los datos se guardan localmente y no se suben a servidores externos
  • Se utiliza tecnología de cifrado para proteger la información sensible
  • Actualizaciones periódicas de los protocolos y medidas de seguridad
  • Limitación estricta de los permisos de acceso a los datos

5. Analítica del sitio web

Este sitio web utiliza Google Analytics y Baidu Analytics para medir el tráfico agregado, como páginas vistas, referentes y ubicación a nivel de país. Estas herramientas pueden establecer cookies en tu navegador. Nunca reciben tus tareas, registros de enfoque ni ningún otro dato creado dentro de la extensión, que permanece en tu propio dispositivo.

6. Actualizaciones de la política

Podemos actualizar esta política de privacidad de vez en cuando. Los cambios significativos se comunicarán a los usuarios mediante notificaciones dentro de la extensión u otros medios adecuados. El uso continuado de nuestro servicio implica la aceptación de la política actualizada.
