常見問題

Clock Max 是免費的嗎？

是的。Clock Max 完全免費，不需要帳號、訂閱或任何內購。

支援哪些提醒方式？

支援單次、每天、每週、工作日/週末、每月指定日期、每月最後一天、每年，以及完全自訂。每個鬧鐘都可設定任意時刻，精確到分鐘。

Clock Max 支援哪些瀏覽器？

Clock Max 已上架 Chrome 線上應用程式商店，可在 Chrome 及其他 Chromium 核心瀏覽器中使用，包括 Microsoft Edge 和 Brave。

使用 Clock Max 需要註冊帳號嗎？

不需要。安裝擴充功能後即可直接建立提醒。

Clock Max 可以離線使用嗎？

可以。鬧鐘、計時器、世界時鐘和待辦清單都在本地執行，斷網也能正常使用。

我的資料儲存在哪裡？

所有鬧鐘、計時、任務與設定都透過瀏覽器儲存 API 儲存在你的裝置本地，不會上傳到我們的伺服器。
