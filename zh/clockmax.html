常见问题

Clock Max 是免费的吗？

是的。Clock Max 完全免费，不需要账号、订阅或任何内购。

支持哪些提醒方式？

支持单次、每天、每周、工作日/周末、每月指定日期、每月最后一天、每年，以及完全自定义。每个闹钟都可设定任意时刻，精确到分钟。

Clock Max 支持哪些浏览器？

Clock Max 已上架 Chrome 应用商店，可在 Chrome 及其他 Chromium 内核浏览器中使用，包括 Microsoft Edge 和 Brave。

使用 Clock Max 需要注册账号吗？

不需要。安装扩展后即可直接创建提醒。

Clock Max 可以离线使用吗？

可以。闹钟、计时器、世界时钟和待办清单都在本地运行，断网也能正常使用。

我的数据保存在哪里？

所有闹钟、计时、任务与设置都通过浏览器存储 API 保存在你的设备本地，不会上传到我们的服务器。
