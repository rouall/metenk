よくある質問

Clock Max は無料ですか？

はい。Clock Max は完全無料で、アカウント、サブスクリプション、アプリ内課金は不要です。

どんなリマインダー設定に対応していますか？

単発、毎日、毎週、平日/週末、毎月の指定日、月末日、毎年、完全カスタムに対応しています。各アラームは 1 分単位で任意の時刻に設定できます。

Clock Max はどのブラウザに対応していますか？

Clock Max は Chrome ウェブストアで公開されており、Chrome および Microsoft Edge や Brave を含む Chromium ベースのブラウザで動作します。

Clock Max の利用にアカウントは必要ですか？

アカウントは不要です。拡張機能をインストールすれば、すぐにリマインダーを作成できます。

Clock Max はオフラインでも使えますか？

はい。アラーム、タイマー、世界時計、ToDo リストはすべてブラウザ内でローカルに動作するため、オフラインでも使えます。

データはどこに保存されますか？

すべてのアラーム、タイマー、タスク、設定はブラウザのストレージ API を使って端末内に保存されます。私たちのサーバーに送信されることはありません。
