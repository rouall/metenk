Política de privacidade do ColorPick Pro

Última atualização: 6 de abril de 2026

Introdução

O ColorPick Pro ("nós", "nosso" ou "a extensão") está comprometido em proteger sua privacidade. Esta política explica como tratamos as informações quando você usa nossa extensão do Chrome.

Informações que coletamos

O ColorPick Pro NÃO coleta, armazena ou transmite nenhuma informação pessoal para servidores externos.

Todos os dados são armazenados localmente no seu dispositivo usando a API de armazenamento nativa do Chrome (chrome.storage.local).

Dados armazenados localmente

Os dados a seguir são armazenados localmente no seu dispositivo para oferecer a funcionalidade da extensão:

  • Cores salvas - Cores que você escolheu e salvou para consultar depois
  • Preferências do usuário - Idioma, tema (claro/escuro) e formato de cópia padrão
  • Atalhos de teclado - Suas preferências de atalhos configuradas
  • Status da avaliação - Se você avaliou a extensão (para evitar avisos repetidos)

Como usamos seus dados

Todos os dados armazenados são usados apenas para:

  • Oferecer a funcionalidade principal da extensão (escolher cores e salvá-las)
  • Lembrar suas preferências entre sessões do navegador
  • Habilitar atalhos de teclado para escolher cores rapidamente

Compartilhamento de dados

Nós NÃO compartilhamos, vendemos ou transmitimos nenhum dado a terceiros. Todos os dados permanecem no seu dispositivo local.

Serviços de terceiros

O ColorPick Pro não se integra a nenhum serviço de análise, publicidade ou rastreamento de terceiros.

Permissões utilizadas

A extensão solicita as seguintes permissões apenas para fins funcionais:

  • storage - Necessário para salvar suas cores e configurações localmente
  • activeTab - Necessário para acessar a aba atual e escolher cores
  • commands - Necessário para registrar atalhos de teclado que permitam escolher cores rapidamente
  • scripting - Necessário para injetar o seletor de cores nas páginas web
  • windows - Necessário para gerenciar as janelas da extensão
  • tabs - Necessário para a comunicação entre a extensão e as páginas web
  • host_permissions (<all_urls>) - Necessário para escolher cores em qualquer site que você visitar

Segurança dos dados

Como todos os dados são armazenados localmente no seu dispositivo, a segurança é mantida pelos mecanismos nativos do navegador. Nós não temos acesso aos seus dados.

Seus direitos

Você tem controle total sobre seus dados:

  • Você pode limpar todas as cores salvas e configurações dentro da extensão
  • Você pode limpar todos os dados desinstalando a extensão
  • Você pode modificar ou excluir cores salvas individualmente dentro da extensão

Alterações nesta política

Podemos atualizar esta política de privacidade periodicamente. Quaisquer alterações serão refletidas na data de Última atualização acima.
